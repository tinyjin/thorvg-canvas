# Docs

The documentation site for `thorvg-canvas`, built with [Docusaurus](https://docusaurus.io).

```sh
yarn build                # from the repository root, builds the package first
yarn docs                 # starts a dev server
yarn workspace thorvg-canvas-docs build
```

`build` runs the scripts in [`examples/`](../examples) and puts the images they save on the Examples page.
